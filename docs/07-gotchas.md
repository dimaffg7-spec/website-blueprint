# 07 - Грабли (проверять на каждом сайте)

Сводный чек-лист ошибок, собранных из ретроспектив реальных проектов. Прочитать ДО старта вёрстки, а не после.

1. **Reveal-on-scroll через `opacity:0` без гейта по `.js`** = невидимый сайт для поисковика (он видит скрытый контент). Гейт: контент видим без JS, анимация включается только при наличии класса `.js`.
2. **Скриншоты превью при прокрутке врут** (многие тулы рендерят с `scrollY=0`, а scroll-hero сбрасывает позицию). Верифицировать вёрстку через инспекцию DOM / computed styles, а не картинкой; для секции внизу - изолировать блок наверх.
3. **Сверять peer-dependencies** библиотек с версией фреймворка (частый источник «билд падает на ровном месте»).
4. **Cookie-согласие и аналитика должны читать одно хранилище** (иначе счётчик молчит у повторных визитов).
5. **OG-image только PNG 1200×630** (SVG соцсети не отображают).
6. **Юр-тексты и цифры - только подтверждённые.** Отзывы в schema - только реальные и видимые. Лица/аватары не выдумывать.
7. **Тяжёлые рантаймы (3D-движки, WebGL, лишний JS) в hero - нет.** CSS решает то же дешевле, Core Web Vitals целы.
8. **Серверные файлы (обработчик формы) на прод сами не попадают** при статической сборке - вести чек-лист «что на проде», заливать отдельно.
9. **Security-review инструменты могут требовать git-origin** - если падает, прогнать чек-лист вручную.
10. **Не `rm -rf` вслепую** - удаляемое сначала показать; временное выносить перемещением, а не удалением.
11. **Гонка сборки и dev-сервера за общий кэш** (при статическом экспорте) - остановить preview перед финальной сборкой; exit code проверять напрямую, не через пайп в `tail`.
12. **Добавлять в git поимённо**, не `git add -A` вслепую (параллельные правки не должны попасть в коммит).
13. **При удалении фичи - искать осиротевшие бинарники** (видео/постеры тянут мегабайты мёртвого веса в прод).
14. **Логотипы - разные правила по типу:** wordmark с прозрачностью обрезать по контенту; лого-плитку (залитый цветной квадрат) НЕ обрезать (растянется); сплошную подложку - убирать в прозрачность цвет-ключом, а не обрезкой.
15. **Резерв высоты в CSS-каруселях считать в `rem`, не `em`** (line-height обычно привязан к корню).
16. **Файлы с секретами (`.env`, конфиги токенов)** - читать только точечно (`grep "^VAR="`), не целиком; писать файловым инструментом, а не `echo` в shell.
17. **Серверный конфиг (`.htaccess` и подобное) может уронить сайт** на старом сервере - проверить совместимость до включения в деплой.
18. **ПДн-логи - над веб-корнем** + закрыть в robots (иначе персональные данные доступны по прямой ссылке).

**Добавлено по итогам следующих проектов (сентябрь 2026):**

19. **Кэш хостинга прячет вашу же работу.** В конфиге стоял `max-age=3600` на css/js: прод отдавал новый файл, браузер показывал старый - каждая правка стилей доходила бы до посетителя через час. Правило: **`no-cache` для css/js, `immutable` только для файлов с хешем в имени**. По коду это не видно - ловится только проверкой в браузере.
20. **`object-fit: cover` дорежет картинку**, если пропорция контейнера не совпадает с пропорцией файла - так съедаются первые буквы заголовков, набранных внутри изображения. Лечится **точной пропорцией контейнера** (`aspect-ratio`), а не перекропом файла.
21. **Дев-сервер врёт про вычисленные стили.** Он пересобирает по запросу, и headless-браузер попадает на недособранное состояние: в одном прогоне `position: static` вместо `sticky`, в другом - высота страницы на тысячи пикселей больше и ложный горизонтальный вылет. **Все визуальные и метрические проверки гонять на продакшн-сборке**, подняв статику простым сервером. Это десять секунд, зато цифры настоящие.
22. **Однопоточный локальный сервер вешает превью** страницы с большим числом картинок: вкладка встаёт, скриншоты уходят в таймаут. Брать многопоточный вариант (`ThreadingHTTPServer` и аналоги).
23. **Скриншот - не доказательство.** Кадр может не обновиться при скрытой панели: скролл отработал, DOM на месте, а снимок пустой. Проверяйте **программно**: вычисленные стили, границы элементов, контраст по формуле WCAG. Расчёт находит невидимую кнопку и слипшиеся карточки там, где глаз по картинке ничего не заметит.
24. **Цвет-на-цвете лечится иерархией, а не подбором оттенка.** Когда карточки и фон стали одного цветового семейства (контраст 1,15), помогла смена схемы: фон насыщеннее карточки - против обычной логики - плюс мягкая тень, которую брендбук запрещал. **У запрета была причина** (он рассчитывал на белые карточки); исчезла причина - исчёз и запрет. Читайте бренд-гайд как набор решений, а не заповедей.
25. **Присланный с рынка компонент нельзя вставлять как есть.** Ценность в идее движения, не в коде: у типового исходника найдутся чужая рамка поверх вашего стиля и собственный скролл-контейнер (`height:100vh; overflow-y:auto`), который перехватывает жест и ломает прокрутку длинной страницы.
26. **Мобильный и десктоп разводить CSS-классами**, а не JS-замером ширины окна: при замере в `useEffect` на первом кадре всегда рисуется мобильная ветка, и виден прыжок.
27. **Повторы в тексте ищутся счётчиком, а не на глаз.** На длинной странице одна и та же фраза легко повторяется 9-10 раз. Посчитайте частотность фраз и режьте по принципу «первое упоминание оставляем, повторы убираем» - уходит объём, не уходит ни одного факта.
28. **Перед удалением по подозрению - проверьте факт.** Файл на подозрительном пути был принят за утечку деплоя, проект удалён - и только потом выяснилось, что рабочий каталог всё время был другим и всё было корректно. Сначала `pwd` и проверка конкретного адреса, потом решение.
29. **Скрипты проверки держите в репозитории**, а не во временной папке: снятие кадров в заданных точках прокрутки и поиск элемента, вылезающего за правый край, нужны на каждом следующем сайте. Иначе следующая сессия напишет их заново.
